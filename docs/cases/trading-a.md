## 2. 制度の歴史（場面の素材）

### 2000年 新人事制度：トレーディング → 事業投資（P.8, P.13）
- 背景：基幹人事制度が導入から20〜30年たち、事業モデルの転換と合わなくなった
- 6つの基本原則：フラットな階層、脱年次・年齢主義、実績重視、脱一律横並び、時価主義、契約概念
- 3つの制度改革
  1. **職責区分**：ポジションを6段階で評価し基本給に反映。同じ資格でも職責が一段重いと基本給110%、軽いと90%（人ではなく役割の評価）
  2. **資格の大くくり化**：多段階 → SP・P・Sの3層
  3. **変動部分の拡大**：年収＝基本給＋成績加算金（個人の貢献）＋業績連動賞与（会社業績）。**上位者ほど変動の比率を高く**
- 起きたこと：昇給・昇格の透明性への懸念、「成果主義が一部の人材だけを励まし、多数の士気を下げる」という声。2006年に、P層を P1〜P3 に細分化した（「次に目指す段階が見えない」「自分の立ち位置が分かりづらい」という声への対応）
- あわせて：準定年退職の拡充・再就職支援、BU制（小単位に損益と人事の責任）と部長ポストの若返り、組織風土調査

### 2019年 人事制度改革：事業投資 → 事業経営（P.9, P.14）
- 目指す姿：「業界のプロ集団」から「経営人材集団」へ
- 3つのキャリアステージ（現場のプロ育成・経営実践・経営人材活用）と4つの重点方針（多様な経験による早期育成、実力主義と適材適所、経営人材の全社的活用と処遇、自律的成長と会社の支援）
- **資格制度と職務給のハイブリッド**：資格制度は残し、経営職務グレード G1〜G5 を導入。G3以上の職務に就くと資格から切り離して職務給（MX）に。離任すると資格制度に戻る。グレードの変更は昇格・降格ではない
- 報酬：M層以上に株式交付制度。経営人材活用ステージは職務の成果に応じたメリハリ
- 育成：評価（貢献度評価）と「成長対話」を分ける。管理職は360度サーベイ。タレントレビューで組織横断に能力と異動希望を見る
- 「ジョブ型」をそのまま真似ず、自社の強み（ローテーションによる育成）を活かすハイブリッドにした（P.9）

### 2024年〜 MC HR Vision「DEAR」（P.18〜25）
- 環境：人材流動化、価値観の多様化、新卒市場の縮小と採用難、会社と社員の関係が「従属からパートナーシップ型へ」
- 見直す要素の例：会社主導のキャリア形成、副業の扱い、働く時間・場所、社員の均質性、上意下達
- 重要職務 約700ポストと人材の可視化、面談 約780件（P.25）。採用の複線化、第二新卒・キャリア採用の強化（P.9）

## 3. 中級の場面の候補（ユーザーに選んでもらう）

どれも「場面の文章に判断の材料が書いてある」形にする。

| # | 場面 | プレイヤーが決めること（選択＋数値） | ミスマッチの例と影響 |
|---|---|---|---|
| A | **2000年・事業モデルの転換期**。年功の職能資格制度が30年続き、若手のプロ人材が育たない | 資格の段階数、職責による基本給の振れ幅（±%）、変動部分の比率と「上位者ほど高く」にするか、脱年次の程度 | 段階を減らしすぎる → 若手が次の目標を見失い、成長の納得感が下がる。変動を一律に大きくする → 多数派の士気が下がる |
| B | **2019年・経営人材の不足**。投資先の経営を任せられる人が足りない | 職務給を入れる範囲（全員／上位職務だけ）、グレードの数、株式報酬の対象、評価と育成対話を分けるか | 全員を職務給にする → ローテーションでの育成と矛盾し、異動を嫌がる人が増える。分けない → 評価の面談が育成に使われない |
| C | **2024年〜・世代交代と採用難**。10年で40〜50代の大半が入れ替わる | キャリア採用の比率、報酬水準、会社主導か公募か（配置）、副業・働く場所 | 新卒一括とローテーション前提のまま → 中途の人が定着しない。流動化に寄せすぎる → 「総力」が落ち一体感が下がる |

## 4. 決めたこと（ユーザーと確認、2026-11-27）
- **期間は創業から今まで**：戦後の創業期（1950年代、P.5〜）から2020年代まで、約70年を通しで遊ぶ。上の A・B・C は、その途中で出る場面の一部になる。1950〜1990年代の場面（P.5〜7、P.10〜11）も素材にする
- **規模は層で計算する仕組みを作る**：単体数千人を、一人ひとりではなく層（年代×資格など）でまとめて計算する
- **ミスマッチの影響は両方**：場面に合わない制度を選ぶと、すぐ効果の倍率で影響が出て、放っておくと失敗の連鎖が始まる

## 5. 決めていないこと
- 約70年をどう遊ばせるか（今のゲームの長さは最長25年。年単位で進める・時代ごとに区切るなど）
- 1950〜1990年代の場面に使う素材の抜き出し（P.5〜7、P.10〜11 をまだ読んでいない）
- 層の分け方と、層の計算を初級（100人超）にも使うか
