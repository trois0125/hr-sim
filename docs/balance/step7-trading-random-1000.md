## バランスの確認（DESIGN.md §11「バランス調整の考え方」）

### 一つの制度だけが常に強くなっていないか

- 要注意：創業期（1〜5年目）の hiring=mid_career（利益・納得感・離職率のすべてで最良）
- 要注意：成熟期（11年目以降）の hiring=mid_career（利益・納得感・離職率のすべてで最良）
- 要注意：成熟期（11年目以降）の workHours=fixed_overtime（利益・納得感・離職率のすべてで最良）
- 要注意：成熟期（11年目以降）の workStyle=hybrid（利益・納得感・離職率のすべてで最良）

### 会社の段階で、利益が最も大きくなる選択肢が変わるか

- grade：創業期は none、成熟期は skill
- evaluation：創業期は competency、成熟期は competency（同じ）
- pay：創業期は market、成熟期は market（同じ）
- bonus：創業期は company_linked、成熟期は company_linked（同じ）
- hiring：創業期は mid_career、成熟期は mid_career（同じ）
- workHours：創業期は variable、成熟期は fixed_overtime
- training：創業期は 0、成熟期は 0.5
- workStyle：創業期は office、成熟期は hybrid
- overtime：創業期は limit45、成熟期は limit20

### 業種ごとに最も良い組み合わせが違うか
