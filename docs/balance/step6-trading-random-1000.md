## バランスの確認（DESIGN.md §11「バランス調整の考え方」）

### 一つの制度だけが常に強くなっていないか

- 要注意：創業期（1〜5年目）の evaluation=multi_rater（利益・納得感・離職率のすべてで最良）
- 要注意：成熟期（11年目以降）の evaluation=competency（利益・納得感・離職率のすべてで最良）
- 要注意：成熟期（11年目以降）の workStyle=hybrid（利益・納得感・離職率のすべてで最良）
- 要注意：成熟期（11年目以降）の overtime=none（利益・納得感・離職率のすべてで最良）

### 会社の段階で、利益が最も大きくなる選択肢が変わるか

- grade：創業期は job、成熟期は none
- evaluation：創業期は multi_rater、成熟期は competency
- pay：創業期は performance、成熟期は performance（同じ）
- bonus：創業期は company_linked、成熟期は company_linked（同じ）
- hiring：創業期は part_time、成熟期は mid_career
- workHours：創業期は variable、成熟期は standard
- training：創業期は 0、成熟期は 0（同じ）
- workStyle：創業期は office、成熟期は hybrid
- overtime：創業期は limit45、成熟期は none
